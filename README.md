# Longevidade

App de acompanhamento do programa Longevidade, por Bartira Rebouças.

Stack: Vite, React, TypeScript, Tailwind, Supabase, Vercel.

## Rodar
1. `cp .env.example .env` e preencher com URL e chave publicável do Supabase
2. `npm install`
3. `npm run dev`

Identidade e vocabulário: `docs/identidade.md`.
